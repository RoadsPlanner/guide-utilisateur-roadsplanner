# Guide utilisateur RoadsPlanner

Guide d'utilisation de l'application RoadsPlanner, pour les utilisateurs : créer un compte, préparer un roadtrip, partager un voyage.

Le site est accessible depuis https://roadsplanner.github.io/guide-utilisateur-roadsplanner/

La documentation du projet (contexte, choix techniques, tests…) se trouve dans le dépôt [documentation-roadsplanner](https://github.com/RoadsPlanner/documentation-roadsplanner).

## Développement

Pour voir le site en local :

```bash
pip install -r requirements.txt
mkdocs serve
```

Le site est ensuite disponible sur http://127.0.0.1:8000/
